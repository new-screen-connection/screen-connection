屏幕连接助手

安装与首次运行

这个应用没有做付费签名/公证：Windows 正在接入开源免费签名通道，macOS 因未购买每年 $99 的开发者账号而不做 Apple 公证。这不会让你的电脑更危险，但系统会让你多走一步——下面每条路都只需要一次。

macOS

首次打开被拦下了

系统会提示「无法验证开发者」或「未验证的开发者」。这是未公证应用的正常提示，三种方式任选其一：

  • 方式一：右键打开（最简单）在「应用程序」里按住 Control 点按（或右键）应用图标，选「打开」，再在弹窗里点「打开」。
  • 方式二：系统设置放行打开「系统设置 → 隐私与安全性」，向下找到关于本应用被拦的提示，点「仍要打开」。
  • 方式三：终端命令复制下面这条命令到「终端」回车执行，去掉网络下载标记：
    xattr -dr com.apple.quarantine "/Applications/屏幕连接助手.app"

为什么更新后「辅助功能」授权又失效了？ad-hoc 签名的应用每次更新后，系统里的旧授权可能失效——这是未公证应用更新后的正常现象，不是出了故障。删掉「系统设置 → 隐私与安全性 → 辅助功能」里的旧条目，重新添加一次即可。应用检测到这种情况时也会主动弹出说明。

Windows

SmartScreen 提示「未知发布者」

点击「更多信息 → 仍要运行」即可继续安装。这只影响来自网络的安装包标记，不改系统安全设置。如果按钮被卡住或想提前解除标记：

Get-ChildItem "C:\Users\你\Downloads" -Recurse | Unblock-File

把上面路径里的 C:\Users\你\Downloads 换成安装包实际所在文件夹。该命令只移除「来自网络」的标记（Zone.Identifier），不会修改任何系统安全设置。

校验

核对 SHA-256

只从官方 GitHub Releases 下载安装包。下载后建议核对哈希值，确认文件完整、来源正确：

正在读取最新 Release 的校验文件…

校验命令（在终端/PowerShell 里执行，把文件名换成你下载的那个）：

shasum -a 256 ~/Downloads/ScreenConnection_x.y.z_x64-setup.exe
Get-FileHash "C:\Users\你\Downloads\ScreenConnection_x.y.z_x64-setup.exe" -Algorithm SHA256

计算结果与 .sha256 文件里的值一致（不区分大小写）就说明文件没被篡改。
